# 🌲 Pengenalan Python untuk Ekologi Lanskap
Selamat datang, Hari ini kita akan belajar bagaimana menggunakan Python sebagai alat bantu pengolahan data ekologi, menggantikan atau melengkapi peran Excel.

### Mengapa Python?
- Mampu mengolah data yang sangat besar dengan cepat.
- Mudah untuk mengulang proses analisis (*reproducible*).
- Memiliki *library* yang kuat untuk statistik dan pemetaan.
